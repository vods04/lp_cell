LPCELL- Sistema de Gerenciamento de Ordens de Serviço

Projeto Integrador em Computação II — UNIVESP

Sobre o projeto

O LPCell é um sistema web desenvolvido para facilitar o gerenciamento de ordens de serviço de uma assistência técnica de celulares, substituindo registros manuais por um processo digital.

Funcionalidades

Cadastro e consulta de ordens de serviço.

Edição e atualização dos registros.

Acompanhamento do status dos serviços.

Armazenamento das informações em banco de dados.

Tecnologias utilizadas

Python e Flask — Backend

HTML, CSS e JavaScript — Frontend

SQLite — Banco de dados

Visual Studio Code — Desenvolvimento

PythonAnywhere — Hospedagem

GitHub — Controle de versão

Desenvolvimento e implantação

O sistema foi inicialmente desenvolvido e testado localmente no Visual Studio Code. Posteriormente, foi hospedado no PythonAnywhere, onde foram realizados ajustes para seu funcionamento na internet.

O repositório reúne o código-fonte do projeto e os registros das atualizações publicadas no GitHub.
