LPCell — Projeto VS Code com banco SQLite

COMO INICIAR NO WINDOWS
1. Instale Python 3.10 ou superior, se ainda não tiver.
2. No VS Code, abra a pasta LPCell (onde está server.py).
3. Abra Terminal > Novo Terminal e execute, uma linha por vez:
   py -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   .venv\Scripts\python.exe server.py
4. Abra no navegador: http://127.0.0.1:5000
5. Mantenha o terminal aberto. Para encerrar, pressione Ctrl+C.
Nas próximas vezes, basta executar o último comando novamente.
Se o comando py não funcionar, tente python no lugar de py.
Não abra o index.html diretamente, pois o sistema utiliza o servidor Python.

O QUE MUDOU

O JavaScript utiliza fetch para se comunicar com a API Python/Flask.
A API valida e salva as ordens de serviço no banco SQLite.
O banco dados/lpcell.db é criado automaticamente.
Cadastro, consulta, edição e mudança de status utilizam esse banco.
Os registros permanecem salvos depois de fechar o navegador.

ARQUIVOS

server.py: servidor, API e criação do banco.
site/index.html: telas e campos.
site/style.css: aparência do sistema.
site/app.js: interação, busca, filtros e comunicação com a API.
requirements.txt: dependências Python.
test_server.py: testes do servidor.

BANCO E BACKUP

O SQLite armazena as informações das ordens de serviço.
Para fazer backup, pare o servidor antes de copiar o arquivo lpcell.db.
Não apague a pasta dados ao atualizar os códigos.
O botão Exportar JSON permite baixar os registros carregados.
O banco com informações reais de clientes não foi incluído no GitHub.

HOSPEDAGEM

O sistema foi desenvolvido inicialmente no VS Code, funcionando no computador.

Depois foi hospedado no PythonAnywhere para permitir acesso pela internet.

Durante a hospedagem, foram feitos alguns ajustes nos arquivos do sistema, principalmente no servidor Python.

Os arquivos atualizados foram adicionados posteriormente ao GitHub.

VERIFICAÇÃO

Para executar os testes:

.venv\Scripts\python.exe -m unittest -v

O arquivo test_server.py contém testes de cadastro, edição, persistência dos dados, validação de CPF e valores, além de verificações das requisições.
